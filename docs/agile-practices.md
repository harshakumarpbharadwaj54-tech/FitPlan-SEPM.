## GitHub Projects or Kanban board

Use a board with these columns:

- **Backlog**
- **To do**
- **In progress** — WIP limit: 2 cards
- **Review** — WIP limit: 2 cards
- **Done**

A card should have a story ID, a short task name, and an owner. If a column reaches its WIP limit, help finish or review existing work before moving more cards into it.

## XP practices to try

- **Test-first development:** Write an expected result for a small profile or workout rule before coding it.
- **Pair programming:** If working with a teammate, take turns driving and reviewing. Record who paired and what task they worked on.
- **Small changes:** Commit one small, understandable change at a time.
- **Continuous feedback:** Run relevant tests after a change and fix failures before adding more work.

Record which practices you actually used and what happened; do not mark a practice complete before trying it.
