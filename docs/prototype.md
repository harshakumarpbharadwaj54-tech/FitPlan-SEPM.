## Weekly plan screen

**FitPlan | Weekly plan**

Plan status: **Draft for validation**

1. The app requests a plan using the user's saved goals, schedule, and preferences.
2. The app checks the result against its documented rules.
3. A plan that fails validation is not shown as accepted.
