# FitPlan User Stories

These stories are a starting backlog. The team should review them and adjust them after collecting real user or role-play feedback.

| ID | User story | Acceptance criteria |
|---|---|---|
| US-01 | As a user, I want to create a profile so that FitPlan can save my preferences. | A valid profile is saved and can be viewed. |
| US-02 | As a user, I want to edit my profile so that my information stays current. | Changes appear after saving and reopening the profile. |
| US-03 | As a user, I want to enter my fitness goal so that a plan can reflect it. | The selected goal is saved and shown in the profile. |
| US-04 | As a user, I want to enter the days I am available so that a plan can fit my schedule. | Saved available days are shown when requesting a plan. |
| US-05 | As a user, I want to record preferences so that suggestions are more relevant to me. | Preferences can be saved and later changed. |
| US-06 | As a user, I want to add a workout entry so that I can keep a record of activity. | A valid entry is saved with its activity and date. |
| US-07 | As a user, I want to view my workout history so that I can review past entries. | My saved entries appear in date order. |
| US-08 | As a user, I want to correct a workout entry so that my log stays accurate. | An edited entry is saved and displayed correctly. |
| US-09 | As a user, I want to record a meal so that I can keep a simple meal log. | A meal description and date can be saved. |
| US-10 | As a user, I want to view my meal history so that I can review previous entries. | My saved meal entries are displayed. |
| US-11 | As a user, I want to request a weekly plan so that I can organize my activity. | FitPlan accepts the request and shows a clear status. |
| US-12 | As a user, I want a plan to consider my goal and available days. | The displayed draft reflects the saved goal and schedule. |
| US-13 | As a user, I want a weekly plan to show rest days. | The draft clearly identifies rest days. |
| US-14 | As a user, I want a plan that fails validation to be rejected. | A failed plan is not shown as accepted and a clear message appears. |
| US-15 | As a user, I want to know when a plan is AI-generated. | The plan displays an AI-generated label. |
| US-16 | As a user, I want a clear message if plan generation is unavailable. | A timeout or service error does not display a plan as accepted. |
| US-17 | As a user, I want to choose what information I share with a trainer. | The user can choose whether to share the selected information. |
| US-18 | As a user, I want to stop sharing information with a trainer. | Access is removed after sharing is withdrawn. |
| US-19 | As a user, I want to request deletion of my project data. | FitPlan explains what will be deleted and confirms the request. |
| US-20 | As a user with a health concern, I want FitPlan to direct me to qualified help. | FitPlan does not present a plan as medical advice and recommends consulting a qualified professional. |
