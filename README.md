# FitPlan: Fitness and Diet Planner

## Project overview
FitPlan is a fitness and diet planning project for users who need workout suggestions that consider their goals, available time, and preferences. Trainers may review information that users choose to share.

## Problem
Generic workout plans may not suit each user's goals, schedule, or constraints.

## Main features
- User profile
- Workout logging
- Meal logging
- Personalized weekly plan generation
- Validation of generated plans against documented safety rules

## Users
- Fitness planner users
- Trainers

## Planned technology
- Python and Django
- PostgreSQL
- Bootstrap
- An approved LLM API

## Project schedule
The project follows the 28-day plan in the SEPM project brief, covering setup, five learning phases, integration, testing, and documentation.

## Success targets
- Test 30 fictional profiles against all 10 defined plan-safety checks.
- Aim for at least 80% test coverage.
- Resolve all blocker issues.
- Finish with a green CI pipeline.

## Project folders
- `docs/` — project documents and diagrams
- `screenshots/` — screenshots of project work and evidence
- `prompts/` — AI prompts and review notes

## Safety and privacy
FitPlan is a student project, not medical advice. Use fictional data in tests and prompts. Never commit API keys, passwords, or private health information.
